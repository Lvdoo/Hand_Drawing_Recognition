# Hand Written Number Recognition

A real-time handwritten digit recognition project using **OpenCV**, **PyTorch**, and **MediaPipe**.
The application detects a handwritten number drawn on a sheet of paper through a webcam, preprocesses the image, and predicts the digit using a trained CNN model.

The project was designed to simulate a clean and fluid digit recognition pipeline with live camera interaction and automatic prediction stabilization.

---

## Features

* Real-time webcam capture
* Handwritten digit localization
* Automatic image preprocessing
* CNN-based digit classification
* MediaPipe hand detection
* Prediction stabilization system
* Confidence filtering
* Noise reduction
* Bounding box visualization
* Real-time prediction display

# How the Project Works

## 1. Webcam Capture

The application continuously captures frames using OpenCV.
The webcam stream is processed frame by frame in real time. 

---

## 2. Hand Detection System

Before making any prediction, the project checks if a hand is visible using **MediaPipe Hand Landmarker**. 

### Important Behavior

If a hand is detected:

* No prediction is made
* Previous predictions are cleared
* The analysis process is reset

This prevents the model from:

* Predicting while the user is still drawing
* Detecting partial numbers
* Producing unstable predictions

The system only starts analyzing when the hand leaves the drawing area. 

---

## 3. Drawing Detection

The project automatically locates the handwritten digit by:

* Converting the image to grayscale
* Applying adaptive thresholding
* Inverting colors
* Removing noise
* Detecting non-zero pixels
* Creating a bounding box around the digit

The largest contour is kept to remove unwanted artifacts and background noise. 

---

## 4. Image Preprocessing

The detected drawing goes through several preprocessing steps before being sent to the CNN model:

* Padding to create a square image
* Resizing to `28x28`
* Tensor conversion
* Normalization using MNIST statistics

This preprocessing pipeline helps reproduce the format of the MNIST dataset used during training. 

---

## 5. CNN Prediction

The project uses a custom Convolutional Neural Network trained on the MNIST dataset.

### CNN Architecture

```text id="p8l5ot"
Input (1x28x28)
→ Conv2D (32 filters)
→ ReLU
→ MaxPooling
→ Conv2D (64 filters)
→ ReLU
→ MaxPooling
→ Flatten
→ Linear (256)
→ Linear (10 classes)
```

The model predicts digits from `0` to `9`.

---

## 6. Prediction Stabilization

Instead of predicting from a single frame, the project analyzes multiple predictions over time.

### Stabilization Logic

* Predictions with confidence below `0.8` are ignored
* Recent predictions are stored in a list
* The most frequent prediction is selected
* The final prediction is validated only if:

  * More than 25 predictions were collected
  * At least 80% agree on the same digit

This reduces:

* Flickering predictions
* Random misclassifications
* Detection instability

When the analysis is complete, the final prediction is displayed on screen.

# Current Challenges

Some handwritten styles remain difficult for the model:

* `7` without a horizontal bar → predicted as `2`
* Certain styles of `4` → predicted as `9`
* Thin pen strokes reduce accuracy
* Pink or light-colored pens are harder to detect
* Bounding boxes can sometimes become unstable

These issues mainly come from:

* Variability in handwriting styles
* Differences between real drawings and MNIST digits
* Noise generated by the camera
